# SSM Privacy Policy

Hosted privacy policy page for **SSM — Simple Soccer Manager**, served via GitHub Pages from
`index.html` in this repo.

Live at: https://digcarlesso.github.io/ssm-privacy-policy/

Kept in its own public repo, separate from the game's private source repo
(`digcarlesso/soccer-manager`), since GitHub Pages on the Free plan only serves from public
repositories.
